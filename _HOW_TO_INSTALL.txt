FREE PERSIAN AUDIO — using Piper (no Azure, no cost, no limits)
================================================================
Your Azure F0 key is quota-capped, so Persian could never finish there. This uses
PIPER, a free open-source neural TTS that runs INSIDE the GitHub runner — no API,
no key, no quota, no rate limit. It writes MP3s with the SAME filenames your app
already expects, so NO app change is needed.

INSTALL
-------
Copy files keeping the SAME folders (overwrite existing):
  • top-level files (incl. generate_audio_piper.py)  -> repo ROOT
  • .github/workflows/generate-fa-audio-piper.yml     -> repo .github/workflows/  (NEW)

RUN
---
Actions -> "Build Persian audio pack (FREE - Piper)" -> Run workflow.
  • Installs Piper + ffmpeg, downloads the Persian voice (~60 MB), then generates
    all 8,405 clips across 3 parallel shards on the runner CPU.
  • Takes roughly 30-60 minutes total; commits every clip at the end. FREE.
  • The self-test prints "SELFTEST: OK" within a minute — no more 429s, ever.

VOICE
-----
Default voice: fa_IR-gyro-medium (clear Persian male). To use a different one,
change the download URL + PIPER_MODEL in the workflow to any of:
  amir, ganji, ganji_adabi, gyro, reza_ibrahim  (all fa_IR ... medium)
Quality note: Piper's Persian is genuine neural voice — very good for flashcards,
though slightly less polished than Azure's Dilara. But it's free and unlimited.

(You can still keep using Azure for other languages that already worked; this
 Piper workflow is only for Persian.)
